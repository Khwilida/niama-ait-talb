# Niama Ait Talb — Site vitrine

Site vitrine bilingue (français/arabe) pour le dépôt d'aliments pour animaux à Meknès.

## Fichiers
- `index.html` : contenu du site
- `style.css` : mise en page responsive et couleurs
- `script.js` : changement de langue et menu mobile
- `assets/entree-depot.jpg` : photo retouchée de l'entrée du dépôt

## Avant la publication
Dans `index.html`, remplacer les textes provisoires :
- `Meknès, Maroc — adresse exacte à ajouter`
- `Numéro à ajouter`
- `Horaires à confirmer`
- Le lien Google Maps générique par l'emplacement exact du dépôt

Vérifier également le nom en arabe et les catégories de produits proposées.

## Publier avec GitHub Pages
1. Créer un nouveau dépôt GitHub, par exemple `niama-ait-talb`.
2. Envoyer les fichiers et le dossier `assets` à la racine du dépôt.
3. Dans le dépôt, ouvrir **Settings → Pages**.
4. Sous **Build and deployment**, choisir **Deploy from a branch**.
5. Sélectionner la branche `main` et le dossier `/ (root)`, puis enregistrer.
6. Attendre la publication ; GitHub affichera l'adresse du site dans la section Pages.

Aucun système de paiement ni backend n'est inclus : il s'agit d'une première version de site vitrine.
